## 開発環境

このプロジェクトは[Volta](https://volta.sh/)を使用してNode.jsとnpmのバージョンを管理している。

## 使用方法

### 依存関係のインストール
```bash
make install
```

### プレビューサーバーの起動
```bash
make up
```

### その他のコマンド
```bash
make clean  # node_modulesの削除
```
